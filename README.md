# agent-cache-cost

Во что обходятся компактизация и промахи кеша в ваших сессиях Claude Code и Codex.

Скрипт читает локальные логи (`~/.claude/projects`, `~/.codex/sessions`) и берёт из них только
счётчики токенов, время запросов и отметки о компактизации. Содержимое переписок не читается и не выводится.
Зависимостей нет, кроме `matplotlib` для графика и `zstd` для сжатых логов Codex.

```bash
python agent_cache_cost.py summary --since 2026-09-03          # сводка по обоим агентам
python agent_cache_cost.py list --tool codex                    # сессии: запросы, компактизации, паузы, макс. контекст
python agent_cache_cost.py session <id> --plot session.png      # одна сессия и её график
```

## Что считается

Стоимость — в условных токенах: цена одного обычного входного токена = 1. Чтение из кеша 0.1, выход 5,
запись в кеш у Claude 1.25 (кеш на 5 минут) или 2 (на час). У Codex надбавки за запись в кеш нет.
Это пропорции цен, а не ваш реальный счёт или подписка.

**Промах кеша** — запрос, который заново обработал больше 20 тысяч токенов и меньше половины прочитал из кеша.
Причина определяется по тому, что случилось перед ним: компактизация, смена модели, пауза больше часа,
пауза 5–60 минут или «прочее». Считается переплата: сколько заплачено сверх цены чтения из кеша.

**Окупаемость компактизации** — за сколько запросов экономия на более короткой истории покрывает
переплату за пересборку кеша сразу после компактизации. Сам запрос на создание сводки в логи не пишется
и не учитывается. Сравнение идёт с воображаемым продолжением без компактизации, которого у предела окна нет.

## Оговорки

- В Codex отдельная сессия — тред; сабагенты считаются отдельными сессиями.
- Codex иногда пишет записи о компактизации в начале возобновлённой сессии; такие не считаются.
- Логи Claude Code по умолчанию хранятся 30 дней (`cleanupPeriodDays`).
